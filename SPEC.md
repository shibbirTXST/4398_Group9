## 1. Overview

This is a mobile app for habit tracking and development. Users are allowed to 
add arbitrary habits, composite habits, set reminders, etc. 

## 2. Stack

**Frontend**:   React Native
**Backend**:    ExpressJS
**Auth**:       Firebase
**DB**:         PostgreSQL
